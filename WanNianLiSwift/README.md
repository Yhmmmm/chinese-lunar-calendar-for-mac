# WanNianLiSwift — Mac 菜单栏万年历

点一下菜单栏，查看农历、节气、放假调休，以及即将到来的生日和纪念日。支持 Apple 芯片与 Intel 芯片，适用于 macOS 13 或更新版本，免费开源。

[下载与产品介绍](../README.md) · [原项目网站](https://calendar.zfdang.com) · [更新历史](../CHANGELOG.md)

这是 [zfdang 原项目](https://github.com/zfdang/chinese-lunar-calendar-for-mac)的个人定制 Fork。此分支的安装包与问题反馈见 [Yhmmmm/chinese-lunar-calendar-for-mac](https://github.com/Yhmmmm/chinese-lunar-calendar-for-mac)。

## 日常使用

- 菜单栏可显示日期图标、`10月28日 周三` 或自定义组合；点击展开 A 版单栏月历，可调整小、标准、大三档尺寸，也可固定为独立窗口。
- 月历从周一开始，每日固定显示农历。点击某一天，下方查看农历、节日和系统日历中的日程时间。
- 系统日历需主动连接并授权；本应用只读日程，点击日程可在系统日历中定位。
- 从月历左下角的“＋”添加家人的农历生日、公历生日或纪念日，支持每年重复或仅一次，也可以导入、导出备份。
- 点击列表图标，查看未来 90 天内最多 6 项自定义日期，点击可跳转到当天。
- 在设置中选择节日分类及英国、美国、法国、德国的公共假日日历，调整外观或开启自动启动。
- 可选择记住上次查看的日期；默认每次打开回到今天。
