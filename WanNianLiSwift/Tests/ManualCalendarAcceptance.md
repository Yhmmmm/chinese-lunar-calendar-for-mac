# 真实系统日历验收

在安装后的 `WanNianLiSwift.app` 中手动执行。使用自己已知的日程核对，不在测试日志或截图中记录真实事件标题。自动化回归使用模拟事件，不会触发 macOS 权限弹窗。

- [ ] 首次点击“连接系统日历”时出现读取权限请求；拒绝后显示权限状态和系统设置入口，月历仍可浏览。
- [ ] 在系统设置授予完整日历访问后，当前可见月份有日程的日期出现标记，选中日列表显示对应事件与全天或起止时间。
- [ ] 对已知的全天、重复和跨日事件，逐日核对标记与列表一致；跨日事件恰在次日零点结束时，次日不应出现标记。
- [ ] 在系统日历中新增、修改或删除一个已知日程后，返回万年历，标记和列表同步更新。
- [ ] 从系统设置撤销日历权限后，返回万年历，旧事件标题和月格标记消失；重新授权后可恢复读取。
- [ ] 快速连续翻月后，最终月格和底部事件仍对应最后停留的月份与选中日期。
- [ ] 点击事件时，若 macOS 请求“自动化”权限，允许后核对系统日历打开到所选日期；能定位具体事件时应选中该事件，无法定位时应停留该日期并显示说明。
- [ ] 拒绝“自动化”权限后，点击事件仍能打开系统日历应用，并提示如何在系统设置中启用定位。
- [ ] 固定窗口后切换日期、窗口大小和辅助窗口；在屏幕边缘增加事件或提示文本时，整个窗口仍在可见区域。

日历读取权限和“自动化”权限是独立的。精确事件定位受系统日历脚本接口及事件 UID 匹配结果影响，不能以应用成功打开作为精确定位通过的证据。
